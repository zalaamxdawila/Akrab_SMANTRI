# Sprint 6 — CSRF dan Mutasi Aman

Status: GREEN_WITH_LIMITATION
Tanggal: 2026-07-29
Reviewer teknis: Codex

## Acceptance criteria

- [x] Token CSRF dibuat secara kriptografis dan dipakai ulang dalam satu sesi.
- [x] Token dibandingkan dengan `hash_equals`.
- [x] Seluruh request POST ditolak dengan status 419 saat token hilang atau salah.
- [x] Seluruh form POST yang terinventarisasi menyertakan token CSRF.
- [x] Pencatatan konsumsi TTD tidak lagi dapat dipicu melalui GET.
- [x] Penghapusan artikel tidak lagi dapat dipicu melalui GET.
- [x] Mutasi sukses memakai pola POST/Redirect/GET.
- [x] Token CSRF dirotasi setelah regenerasi sesi terautentikasi.

## Bukti verifikasi

- PHP lint — PASS untuk seluruh file PHP.
- PHPUnit — 35 test, 82 assertion, seluruhnya PASS.
- Tes khusus CSRF/POST-only — 16 test, 45 assertion, seluruhnya PASS.
- Regression test membuktikan pola GET lama terdeteksi sebelum implementasi lalu kembali hijau sesudah perbaikan.

## Keterbatasan

Pengujian HTTP nyata melalui browser dan HTTPS belum dapat dilakukan karena environment database staging belum tersedia. Verifikasi status 419, header cookie, login, logout, dan rotasi token melalui browser tetap wajib sebelum produksi.

## Keputusan

GO untuk melanjutkan development. HOLD untuk deployment produksi sampai keterbatasan runtime pada CP-03 ditutup.

## Rollback

Revert helper CSRF, field pada form, dan perubahan handler sebagai satu unit. Jangan mengaktifkan kembali mutasi melalui GET.
