# Sprint 7 — Authorization dan Least Privilege

Status: GREEN_WITH_LIMITATION
Tanggal: 2026-07-29
Reviewer teknis: Codex

## Acceptance criteria

- [x] Role aplikasi memiliki allowlist eksplisit.
- [x] Role dan aksi yang tidak dikenal ditolak secara default.
- [x] Login tidak memiliki fallback ke privilege UKS.
- [x] Role yang tidak cocok menghasilkan HTTP 403.
- [x] Data siswa pada dashboard orang tua berasal dari relasi milik session dan wajib ber-role siswa.
- [x] Artikel UKS hanya dapat dilihat, diubah, dan dihapus oleh UKS pembuatnya.
- [x] Surat rujukan hanya dapat menarget user ber-role siswa.
- [x] Balasan konsultasi hanya untuk konsultasi siswa yang masih menunggu dan dikunci dalam transaction.
- [x] QR scanner tidak menerima scanned URL sebagai tujuan redirect.
- [x] Akun database runtime dan migration memakai environment credential terpisah.

## Keterbatasan

Traversal test saat ini menguji policy dan boundary query secara otomatis, tetapi belum menjalankan sesi nyata untuk seluruh role terhadap database staging. Grant database runtime juga harus diterapkan dan dibuktikan pada hosting; source kini memisahkan credential runtime dari credential migration.

## Keputusan

GO untuk development Sprint 8. HOLD produksi sampai traversal HTTP staging dan verifikasi database grants selesai.

## Rollback

Revert policy, query ownership, dan pemisahan credential sebagai satu unit. Jangan mengembalikan fallback role UKS atau external QR redirect.
