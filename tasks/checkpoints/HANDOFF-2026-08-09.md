## Completed in this batch

- [x] Single-domain routing and production error handling were tightened.
- [x] Questionnaire identity fields are rebuilt on the server, archived rows no
  longer extend the cooldown, and internal exception details are not exposed.
- [x] Password reset tokens are stored as SHA-256 digests, shown only once to
  the superadmin, expired and consumed transactionally, and covered by migration
  `014_hash_password_reset_tokens`.
- [x] Password login, reset requests, and passkey flows have session-based rate
  limits.
- [x] Passkey actions use POST and CSRF protection, one-time challenges, central
  account-status policy, owner-scoped credential lookup, required user
  verification, signature-counter validation, and audit events.
- [x] The release allowlist includes only the required manual WebAuthn dependency;
  local diagnostics, PHPMailer experiments, and Nodemailer experiments are not
  packaged.
- [x] WebAuthn vendored source was byte-compared with upstream tag `v2.2.0`; the
  upstream license and local version marker are included.
- [x] CI now runs `composer audit --locked --no-interaction`.
- [x] MariaDB metadata checks use quoted literals rather than unsupported
  prepared-statement placeholders in `SHOW` statements.
