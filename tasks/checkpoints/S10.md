# Sprint 10 — Hardening CSV Import/Export

Status: GREEN_WITH_LIMITATION
Tanggal: 2026-07-29
Reviewer teknis: Codex

## Acceptance criteria

- [x] Upload dibatasi 2 MB dan ekstensi serta MIME CSV diverifikasi.
- [x] Header harus tepat `Nama,Kelas,Username,Password`.
- [x] Baris divalidasi dengan whitelist username, panjang, dan password.
- [x] Import dibatasi 1.000 baris, 4.096 karakter per baris, dan 10 detik.
- [x] Import menggunakan transaction batch dan rollback saat kegagalan fatal.
- [x] Hash file mencegah batch yang sama diproses ulang.
- [x] Duplikasi username dilewati secara deterministik.
- [x] Export menetralkan cell yang diawali `=`, `+`, `-`, atau `@`.
- [x] Batch import tercatat pada tabel `csv_import_batches`.
