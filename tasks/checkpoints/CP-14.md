## Gate decision

Kernel aman disimpan di source karena tidak memiliki UI publik dan
`AKRAB_SUPERADMIN_ENABLED=false` tetap menjadi default. CP-14 belum GREEN sampai
DDL migration dibuktikan pada engine target. Persetujuan pengguna untuk
melanjutkan satu sprint dicatat sebagai risk acceptance lokal, bukan production
GO.

Sprint 27 dapat dilanjutkan hanya berdasarkan instruksi “lanjutkan” berikutnya.
Risiko rehearsal tetap terbuka dan harus diselesaikan sebelum activation atau
deployment.

## Rollback

1. Pastikan `AKRAB_SUPERADMIN_ENABLED=false`.
2. Revert commit Sprint 26 jika migration belum dijalankan.
3. Jika migration sudah direhearsal, pertahankan tabel/audit additive dan
   rollback kode melalui feature flag; jangan menjalankan DDL destructive.
