# Sprint 5 — Session Hardening

Status: GREEN_WITH_LIMITATION
Tanggal: 2026-07-29
Reviewer teknis: Codex

## Acceptance criteria

- [x] Production cookie memakai Secure, HttpOnly, dan SameSite=Lax.
- [x] Session strict mode dan cookie-only aktif.
- [x] Session ID diregenerasi setelah login.
- [x] Session ID diregenerasi setelah perubahan password.
- [x] Idle timeout default 30 menit.
- [x] Absolute timeout default 8 jam.
- [x] Logout menghapus data server dan cookie browser.
- [x] Timeout membuat session ID baru, bukan memakai ID kedaluwarsa.

## Bukti verifikasi

- PHP lint — PASS.
- PHPUnit — 19 test, 37 assertion, seluruhnya PASS.
- Audit pemanggilan session menunjukkan lifecycle terpusat pada `config/session.php`.

## Keterbatasan

Inspeksi header `Set-Cookie` melalui browser/HTTPS belum dilakukan karena aplikasi belum memiliki environment database staging lokal. Pemeriksaan runtime wajib dilakukan sebelum CP-03 GREEN.

## Rollback

Revert helper session dan pemanggilnya sebagai satu unit. Jangan mengembalikan `session_start()` tersebar atau login tanpa regeneration.
